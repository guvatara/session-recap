# Session Recap Lite

Небольшой модуль для [Foundry VTT](https://foundryvtt.com/) (v12–14): запоминает яркие моменты сессии и по команде выводит сводку в чат. Системно-независим — работает с D&D 5e, PF2e и любыми другими системами, где бросается d20.

## Что делает

- 🎯 Запоминает **натуральные 20** на d20
- 💥 Запоминает **натуральные 1** на d20
- 📝 Позволяет GM добавлять **ручные заметки**
- ⚔️ Считает **нанесённый урон** за сессию (по акторам, dnd5e и PF2e)
- 🤖 Может **автоматически публиковать сводку** при завершении боя (настраивается)
- 📜 По команде `/recap` публикует сводку сессии в чат
- События хранятся в настройках мира и переживают перезапуск сервера

## Установка

В Foundry VTT: **Add-on Modules** → **Install Module** → в поле **Manifest URL** вставить:

```
https://github.com/guvatara/session-recap/releases/latest/download/module.json
```

## Использование

| Команда | Действие |
|---|---|
| `/recap` | Опубликовать сводку (видят все) |
| `/recap gm` | Сводку видит только GM |
| `/recap note Текст` | Добавить заметку в сводку |
| `/recap clear` | Очистить события (перед новой сессией) |

## Разработка

Структура модуля:

```
module.json               — манифест
scripts/session-recap.js  — логика (хуки Foundry)
styles/session-recap.css  — стили сводки
```

Релизы собираются автоматически: при публикации релиза на GitHub workflow подставляет версию в `module.json`, собирает `module.zip` и прикрепляет оба файла к релизу.
